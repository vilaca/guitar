# Edge-Zero II tremolo: setup notes for the Ibanez XPTB720

What the Ibanez Edge-Zero II manual says that applies to the XPTB720's Edge-Zero II-7 bridge, and what it implies for the current G standard tuning.

- **Source:** [`manuals/ibanez-edge-zero-ii-tremolo.pdf`](manuals/ibanez-edge-zero-ii-tremolo.pdf), the Ibanez "Edge-Zero2 tremolo bridge" manual (4 pages, English). The procedures below are paraphrased from it.
- **Also used:** the XPTB720 parts catalogue entry, which lists the tremolo as "Edge-Zero II-7 spring hook version, black, 7 string" (see `ibanez-xptb720.md`).
- **Labels:** "inference" marks a conclusion drawn from the manual rather than stated in it.

## Which manual sections apply

The manual covers the standard Edge-Zero II and has separate instructions for models with and without a "zero point system". Neither the product page nor the parts catalogue says whether the XPTB720's Edge-Zero II-7 has that system.

- **Inference:** the catalogue's "spring hook version" suggests conventional tremolo springs hooked onto the claw. The manual's "not equipped with the zero point system" sections would then be the ones that apply.
- **How to check (inference from which parts each set of instructions names):** a zero point system has a spring adjustment knob, main and sub springs, a stop rod and a stopper at the back. A conventional set-up has tremolo springs and a spring lock in the rear cavity.
- **Seven strings:** the manual doesn't mention the 7-string version.

## Procedures

### Tremolo angle (no zero point system)

1. With the guitar tuned correctly, check the tremolo angle. The target is roughly parallel to the body surface.
2. If the tremolo tilts forward, tighten the spring screws through the slit in the spring cover on the back of the body.
3. If it tilts toward the rear, loosen the screws.
4. Adjusting the springs changes the tuning, so retune repeatedly while adjusting.

### Springs (no zero point system)

- Factory set-up is three tremolo springs in parallel.
- When the balance between string tension and spring tension changes significantly, such as with a different string gauge or a dropped tuning, the number of springs or how they are installed may need to change.
- **To increase tension:** remove the spring lock with a Philips screwdriver and install the outer two springs diagonally.
- **To decrease tension:** remove the centre spring.
- Four or more springs go on the screw holes used for the spring lock, after which the spring lock can't be fitted.
- **Safety:** loosen the strings sufficiently before fitting or removing springs. If all springs are removed, the tremolo unit comes off the guitar. To refit, seat the knife edge in the groove of the stud bolts, then install the springs.

### Zero point system (if fitted)

- When correctly adjusted, the stop rod sits firmly against the tremolo block and touches the stopper, and the tremolo is roughly parallel to the body.
- If the stop rod isn't touching the stopper, turn the spring adjustment knob toward plus to tighten the main spring.
- If the tremolo block isn't firmly against the stop rod (tilted toward the rear), turn the knob toward minus.
- The system can be disabled to use the bridge as a conventional floating bridge. Hold the arm up, remove the stop rod and the sub spring, then set the angle with the spring adjustment knob: plus if tilted forward, minus if tilted toward the rear.

### Stud lock

1. Put a 2 mm hex key through the hole in the top of the stud bolt.
2. Turn the stud lock bolt clockwise until it contacts the anchor nut and can't turn.
3. Loosening the bolt releases the stud lock.

### Action

- Turn the stud bolts on the left and right of the tremolo with a 3 mm hex key. This sets the height of the whole unit. Individual strings can't be adjusted.
- Make sure the string stopper bolts are tight before tuning.

### Intonation

1. Loosen the pressure pad bolts of the locking nut (3 mm) and loosen the strings enough.
2. Loosen the saddle lock bolts (2 mm) and move the saddle.
3. Before checking intonation, tighten the saddle lock bolts and tune the guitar correctly.
4. When finished, tighten the saddle lock bolts and the pressure pad bolts.

### Replacing strings

1. Loosen the locking nut's pressure pad bolts (3 mm) and take the string off the tuning peg.
2. Loosen the string stopper bolt (3 mm), pull the string out of the saddle and remove it.
3. Cut the ball end off the new string.
4. Put the cut end between the saddle and the string holder block and tighten the stopper bolt.
5. Wind the string onto the tuning peg and tune it.
6. When tuning is done, tighten the pressure pad bolts.

On a bridge without the zero point system, removing all strings at once changes the tremolo angle a lot, so the manual recommends changing strings one at a time. If all come off together, wedge a cloth under the tremolo to hold it. The manual calls the missing feature the "zero cross system" in this note, which looks like a slip for "zero point system".

### Fine tuning

After the strings are locked at the nut, the fine tuners still adjust each string. The range is widest if every fine tuning bolt starts near the centre of its travel.

## Implications for G standard tuning

The guitar's factory tuning is A standard and it is now tuned a whole tone lower, to G standard. The guitar's current spring count, tremolo angle and string gauges aren't recorded.

- **Calculated:** at the factory string gauges, the plain strings carry about 20% less tension in G standard than in A standard (see `comparison.md`).
- **Manual:** it names "a different gauge of strings or a dropped tuning" as reasons to change the number of springs, and says removing the centre spring decreases tension.
- **Inference:** lower string tension generally calls for lower spring tension, so a spring removed from the three-spring factory set-up is the manual's way to decrease it. Heavier strings would call for the opposite. The manual gives no rule for a specific tuning or gauge, so the angle check above is the test.
- **After any change:** retune, check the angle and re-check intonation.
