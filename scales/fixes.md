# Scale guide review decisions

## Playing instructions

| Review item | Status | Reason |
| --- | --- | --- |
| 1. Phrygian piano-page references | Applied | The loop-page caption now sends players to page 2 for triads and page 7 for extended chords. A reference to page 7 alone missed the triads. |
| 2. Bebop six-note slide | Already applied | Page 2 names string 7 in the wide diagonal. The separate compact pattern plays three notes per string. |
| 3. Change the Gm9 voicing | Not applied | With G2 in the bass, A3 already sounds a ninth above the root. The adjacent A3 and Bb3 are a valid voicing. Moving A to the top would change its sound. |
| 4. E minor ending on a 22-fret guitar | Already applied | On page 2, string 1 carries B5 at fret 19 and D6 at fret 22. Players can stop there before the final E6 at fret 24. |

## Optional polish and suggested improvements

| Review item | Status | Reason |
| --- | --- | --- |
| Match the typefaces | Not applied | The guides use different typefaces by design in their generators. The bebop and pentatonic guides use Bitstream Vera. A font change would require checking the spacing on every page. |
| Add a Phrygian fretboard map and chord-spelling table | Not applied | Both would be new reference material. The current correction points to the existing keyboard diagrams. |
| Set PDF metadata titles | Already applied | All three generated PDFs have descriptive document titles. |
| A. Add guitar chord shapes | Not applied | This would add an accompaniment lesson to guides that currently teach the guitar scale and illustrate keyboard voicings. |
| B. Share one layout module | Not applied | Each generator is documented as independently runnable. The Phrygian loop pages already use one shared caption. |
| C. Move playing tips to a separate PDF | Not applied | Each guide can be printed and used on its own, and its tips include examples specific to that scale. |
| D. Add drop-A rows | Not applied | The scale guides use B standard throughout, as requested. |
| E. Add multiple fixed-position boxes | Not applied as proposed | Phrygian and bebop already have a compact three-note-per-string pattern. The pentatonic guide uses the two requested diagonals. Further positions would be additional exercises. |
| F. Clarify the bebop title | Already applied | The title names the B♭ dominant bebop collection and the G-centred riff. The collection contains both A♭ and A, and loop 03 centres on B♭7. |
| G. Add Roman numerals to all loops | Not applied | This would require analysing each loop in its own tonal context. The proposed equivalence was incorrect. Gm to A♭ is i to ♭II in G, while Em to Dsus4 is i to ♭VIIsus4 in E. |
| H. Mark the optional blue note on the pentatonic grid | Not applied | Page 1 maps the five pentatonic notes. The blues page introduces B♭ separately as an optional addition. |
| I. Trim the loops and add variation prompts | Not applied | Each guide provides the advertised 49 loops with individual playing directions. Reducing their number would change the collection. |
| J. Tighten page spacing | Not applied | The whitespace separates the fretboard diagrams from the reading instructions. Layout compression was an optional print preference. |
| J. Add tab legends | Already applied in substance | The pattern pages identify bold roots and parenthesized neighboring frets. The Phrygian legend applies to both tabs on its page. |
